# Permission documents index

These documents are drafts to help obtain and record authorization. None of them grants rights by itself.

| Document | PDF | Purpose | Who signs it |
| --- | --- | --- | --- |
| [`PERMISSION_REQUEST_TEMPLATE.md`](PERMISSION_REQUEST_TEMPLATE.md) | [PDF](PERMISSION_REQUEST_TEMPLATE.pdf) | Initial request letter asking the rights holder for permission. | Repository owner sends it. |
| [`PERMISSION_AGREEMENT_DRAFT.md`](PERMISSION_AGREEMENT_DRAFT.md) | [PDF](PERMISSION_AGREEMENT_DRAFT.pdf) | Formal license agreement granting porting and redistribution rights. | **Must be signed by an authorized rights-holder representative** and by the repository owner. |
| [`OWNER_RIGHTS_ATTESTATION.md`](OWNER_RIGHTS_ATTESTATION.md) | [PDF](OWNER_RIGHTS_ATTESTATION.pdf) | Repository owner’s declaration that signed authorization has been obtained. | Repository owner signs it; attach the executed agreement as Exhibit A. |
| [`RIGHTS_CHECKLIST.md`](RIGHTS_CHECKLIST.md) | — | Gate that must pass before any public release. | Maintainer reviews. |

## Important

- Do **not** fill in or sign Rovio’s name, signature, or title unless you are an authorized Rovio representative.
- A draft agreement, an unsigned attestation, or a file hosted on a public mirror is **not** proof of redistribution rights.
- The LimeWire mirror provided on 2026-10-24 returned **Error 410 — “This link no longer works.”** The PC base archive still needs to be uploaded to the repository or attached in chat.
- Until the rights checklist is satisfied, no game binaries or assets will be committed to this branch or included in a GitHub Release.
